> A comprehensive Library Management System with responsive UI, MongoDB backend, and real-time transaction tracking.

## 🚀 Features

### 📖 Book Management
- ✅ Add, Edit, Delete Books
- 🔍 Advanced Search by Title, Author, ISBN
- 📊 Track Book Availability Status
- 🏷️ Categorize Books by Genre
- 📈 Real-time Stock Monitoring

### 👥 Member Management
- 👤 Register New Members
- 🔄 Update Member Information
- 📋 Track Borrowing History
- 🎫 Unique Member ID Generation
- 📊 Member Activity Monitoring

### 🔄 Transaction Management
- 📤 Issue Books to Members
- 📥 Return Books with Fine Calculation
- ⏰ Automatic Overdue Detection
- 💰 Fine Management System
- 📅 Due Date Tracking

### 📊 Reports & Analytics
- 📈 Dashboard with Key Metrics
- 📊 Real-time Statistics
- 📉 Borrowing Trends
- 💵 Fine Collection Reports
- 📑 Transaction History

## 🛠️ Technology Stack

### Backend
- 🐍 **Python 3.8+** - Core Programming Language
- 🌶️ **Flask 2.3.3** - Web Framework
- 🍃 **MongoDB** - NoSQL Database
- 🔌 **PyMongo** - MongoDB Driver

### Frontend
- 🎨 **HTML5/CSS3** - Structure & Styling
- 🎭 **Bootstrap 5** - Responsive UI Framework
- ⚡ **JavaScript/jQuery** - Dynamic Interactions
- 📱 **Font Awesome** - Icons

### Development Tools
- 🛠️ **Git** - Version Control
- 📦 **pip** - Package Management
- 🔐 **python-dotenv** - Environment Variables

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
